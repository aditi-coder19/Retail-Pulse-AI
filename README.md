# RetailPulse AI – Retail Analytics Dashboard

## 📊 Project Overview
RetailPulse AI is an interactive retail analytics project developed using Microsoft Power BI. It helps analyze retail business performance through interactive dashboards, key performance indicators (KPIs), charts, and filters.

The project transforms retail transaction data into meaningful insights to support data-driven business decisions.

## 🎯 Objectives
- Analyze overall sales and business performance.
- Identify top-performing products and customer segments.
- Understand regional and monthly sales trends.
- Evaluate revenue, profitability, and customer behavior.
- Highlight potential inventory risks.
- Present business insights through interactive dashboards.

## 🛠️ Technologies Used
- Microsoft Power BI
- Power Query for data cleaning and transformation
- DAX for calculated measures and KPIs
- Data visualization and business analytics
- Excel / CSV for data handling

## 📈 Dashboard Features
The project includes 12 dashboard pages covering:

1. Executive Summary
2. Sales Trend Analysis
3. Product Performance
4. Customer Analytics
5. Region and Country Sales
6. Monthly and Seasonal Analysis
7. Customer Behaviour
8. Profit and Revenue Analysis
9. Inventory Risk Analysis
10. Order and Transaction Analysis
11. Advanced Analytics
12. Interactive Filters and Analysis

## 🔍 Key Insights
The dashboards are designed to help users explore sales patterns, customer purchasing behavior, product performance, regional contributions, and inventory-related risks.

## 🚀 How to Use
1. Download the Power BI `.pbix` file from this repository.
2. Open it using Microsoft Power BI Desktop.
3. Refresh the data source if required and available.
4. Use the slicers, filters, KPIs, and charts to explore the dashboard.
